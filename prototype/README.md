# UI 交互原型

这是 PRD v0.2 的可点击 UI 原型，**不是生产 Vue3 代码**，不连接后端，数据全部是本地 Mock。

## 运行

直接双击 `index.html` 即可；若浏览器限制相对资源，可在项目根目录运行：

```bash
cd D:\dev-soff\knowledge-card-generato-main
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

打开 `http://127.0.0.1:8765/`。

## 可演示的交互

1. 学习首页 → 今日任务、继续练习、演示路径。
2. 单词库 → 搜索、主题/词性筛选、选中单词、单词详情。
3. 分类默写 → 汉译英、听音写词、英译汉、音标写词，题量与顺序切换。
4. 作答 → 输入、提交、故意答错、首字母提示、拼写差异、下一题。
5. 结果 → 指标、错词、只练本次错词。
6. 错词复习 → 重练单词或重练全部。
7. 词库导入 → 载入示例 PDF、解析进度、低置信度校对。
8. 设置 → 发音、题量、来源信息。

## 说明

- 发音使用浏览器 SpeechSynthesis 演示，并明确提示“设备语音”；生产环境由后端统一代理合法音频。
- PDF 校对为示例数据，真实生产需要异步解析、字段置信度、重复冲突和发布版本。
- 关键控件保留 `data-testid`，便于后续 Playwright/UI 自动化迁移。
- 生产前端建议 Vue3 + Vite + Pinia + Vue Router；本原型只用于交互与视觉评审。
